# 从零到卖出第一单：完整操作流程

> 面向：**卖家**（你和你同伴）
> 读完这一份就能开卖，不需要懂代码。
> 最后更新：2026-10-20（对应 EXE `97,495,552` 字节版本）

---

## 0. 一分钟看懂

```
【准备】上传 EXE 到网盘  →  生成一批卡密  →  商品上架
            ↓
【成交】买家付款  →  你把「网盘链接 + 一张卡密」发给他
            ↓
【激活】买家双击 exe → 浏览器打开 → 填卡密 → 点激活 → 2~4 秒完成
            ↓
【售后】到期前 7 天界面提醒  →  到期后还有 12 小时宽限  →  续期发新卡
```

**5 个环节里，只有「发货」需要你动手**（复制粘贴两样东西），其余都是自动的。

---

## 1. 准备阶段（只做一次，约 30 分钟）

### 1.1 你手上必须有这三样

| 东西 | 在哪 | 用途 |
| --- | --- | --- |
| **EXE** | `dist\totoro-heaven.exe` | 卖给买家的程序本体 |
| **激活服务地址** | `https://totoro-license.pages.dev` | 程序后台自动连，买家无感 |
| **管理密钥** | 第一次部署时生成的 48 位字符串 | **发卡用**，绝不能给买家 |

> ⚠️ 管理密钥只在你自己的电脑上保存，**不要**写进任何文档、不要发群里。
> 丢了不要紧 —— 可以在 Cloudflare 后台重新设，但要重新部署一次。

### 1.2 上传 EXE 到网盘

1. 把 `dist\totoro-heaven.exe` 传到网盘（百度/阿里/夸克都行）
2. 记下**分享链接 + 提取码**
3. **建议设成"永久有效"**，否则买家过几天点开就失效了

### 1.3 生成第一批卡密

**`Win + R` → 输入 `powershell` → 回车**，然后整段粘进去（回车执行）：

```powershell
$URL   = "https://totoro-license.pages.dev"
$TOKEN = "<你的管理密钥>"

Invoke-RestMethod -Method Post -Uri "$URL/admin/cards" `
  -Headers @{ Authorization = "Bearer $TOKEN" } `
  -ContentType "application/json" `
  -Body '{"count":50,"days":365,"sub":"闲鱼订单"}'
```

**返回这样一段就是成功：**

```json
{ "ok": true, "count": 50, "days": 365, "cards": ["TH-A8TW-G2RD", "TH-K8AR-NJKM", ...] }
```

**把这 50 张复制到记事本，一行一张，存好。**

> **参数说明**
> - `count`：一次发多少张（最多 200）
> - `days`：有效期天数（365 = 年卡，30 = 月卡）
> - `sub`：备注，只给你自己看
>
> **卖什么卡就发什么批次**：年卡发 `days:365`，月卡发 `days:30`，别混。

## 2. 上架

在闲鱼（或别的平台）发布商品，标题和描述建议写清：

```
【龙猫天堂】阳光跑助手 · Windows 版 · 电脑端
✅ 拍下即发下载链接 + 激活卡密
✅ 支持 Win10 / Win11 64 位
✅ 一次购买一年有效
⚠️ 一机一码，换电脑需重新购买
```

**商品描述里必须写的三条**（能少掉一半售后）：

1. **一机一码**，换电脑/重装系统要重新买
2. 杀毒软件可能**误报**，加白名单即可
3. 首次运行会弹 **SmartScreen 蓝色警告**，点「更多信息 → 仍要运行」

## 3. 卖出一单（每单 1 分钟）

**买家付款后，你发这一段：**

```
链接：<你的网盘链接>
提取码：<提取码>
卡密：TH-A8TW-G2RD
```

**然后继续做：**

1. 在记事本里**把这张卡密删掉**（或标记为已用），避免重复发给别人
2. 等买家激活成功（通常 1~2 分钟内会回你"好了"）

> 一次发 50 张，大概能卖 50 单。卖完再跑一次生成命令。

---

## 4. 买家激活（买家自己完成，你不用管）

| 买家看到 | 说明 |
| --- | --- |
| 双击 exe → **蓝色 SmartScreen 警告** | 点「更多信息」→「仍要运行」 |
| 浏览器自动打开 → 停在**「授权」页** | 因为没授权，程序自己跳过来的，正常 |
| 页面上**只有一个「输入卡密激活」框** | 机器码和证书都在折叠区里，不用管 |
| 填卡密 → 点「卡密激活」 | 等他 2~4 秒 |
| 顶栏变「**已授权 · 365 天**」 | 完成，之后每次直接进工作台 |

**激活时程序在后台做了什么**（你不用讲给买家，但自己要知道）：

```
程序自动读本机机器码 → 连 totoro-license.pages.dev
  → 服务器验卡密（是否用过）→ 用私钥现签一张绑定这台机器的证书
  → 程序本地验签通过 → 存到本机 → 之后完全离线可用
```

---

## 5. 续期

到期前 **7 天**，程序界面开始提醒（顶栏变黄「剩 N 天」）。

**买家找你续期时：**

1. 从记事本拿一张**新卡密**（或现发一批）
2. 发给他："把新卡密填进退出的授权页就行"
3. 他填进去 → 有效期从**激活那一刻**重新计算

> 注意：续期是**换一张新卡**，不是在原证书上延长时间。
> 旧卡密已经用掉了，不能再用。

---

## 6. 买家换电脑 / 重装系统

**机器码变了 ⇒ 旧卡密失效**（一机一码）。

处理方式：**卖他一张新卡**。

如果买家抱怨，话术：

> 亲，授权是跟电脑绑定的，换电脑确实要重新开通一次哈。
> 这是为了防止一张卡被到处复制，也保护你的权益～

---

## 7. 退款 / 纠纷

**原则：能退就退，别纠缠。** 几十块的东西，纠缠的成本远高于退款。

**什么情况该退：**

- 买家电脑是 32 位系统 / Win7 / Mac（跑不了）
- 激活反复失败，你排查不出原因
- 买家说"和描述不符"

**怎么退：** 平台走退款流程。**已用掉的卡密作废即可**（不用回收）。

**什么情况可以拒绝：**

- "我换电脑了要退" → 不是质量问题
- "我朋友说不好用" → 主观评价
- 已经用了好几个月

## 8. 每日 / 每周维护

### 每天

- 看一眼前一天有没有买家报问题
- 卡密快用完了就再发一批

### 每周（5 分钟）

**查库存**：

```powershell
$URL   = "https://totoro-license.pages.dev"
$TOKEN = "<你的管理密钥>"

Invoke-RestMethod -Uri "$URL/admin/cards?limit=100" -Headers @{ Authorization = "Bearer $TOKEN" }
```

返回：

```json
{ "total": 50, "unusedCount": 47, "usedCount": 3, ... }
```

- `unusedCount` = 还能卖多少
- 剩不到 10 张就该发新的一批

> ⚠️ **刚发出去的卡最多 60 秒后**才会出现在这个列表里（Cloudflare KV 的机制）。
> 不影响激活，只是列表有延迟。

---

## 9. 出问题怎么查

### 买家说"激活不了"

**先问清楚他看到的提示文字**，对照下表：

| 提示 | 原因 | 怎么处理 |
| --- | --- | --- |
| 卡密不存在 | 输错 / 你发错 | 核对卡密，注意别把 0 和 O、1 和 I 弄混 |
| 这张卡密已被使用过了 | 已经被激活过一台机器 | 查库存看是不是被用掉了；确实是用过就卖新卡 |
| 无法连接激活服务器 | 买家网络问题 / 服务挂了 | 让他换网络重试；你自己打开 `https://totoro-license.pages.dev/health` 看服务是否正常 |
| **尝试失败次数过多，请 10 分钟后再试** | 连错 6 次被限流（防撞库） | 让他核对卡密后**等 10 分钟**再试；别反复点 |
| 未启用在线激活 | 他装的是**旧版 EXE** | 让他重新下载你最新的（`97,495,552` 字节那个） |
| 双击没反应 / 一闪而过 | 系统环境问题 | 让他右键「**以管理员身份运行**」 |
| 杀毒软件报毒 | 未签名 EXE 的正常误报 | 让他加白名单 |

### 你自己验证服务是否正常

浏览器打开：

```
https://totoro-license.pages.dev/health
```

必须看到：

```json
{"ok":true,"keyLoaded":true,"kvBound":true,...}
```

- `keyLoaded: false` → 私钥丢了，**所有新激活都会失败**，要重新部署
- `kvBound: false` → 卡密库没绑上，同上

## 10. 关键数字（记住这几个）

| 项目 | 数值 | 说明 |
| --- | --- | --- |
| 卡密 | `TH-XXXX-XXXX` | 一次性、一机一码 |
| 离线宽限 | **12 小时** | 到期后还能用半天，之后停服 |
| 每日发卡上限 | **1000 张** | Cloudflare 免费额度，够用 |
| 发卡后多久能看到库存 | 最多 **60 秒** | 不影响激活 |
| 激活耗时 | **2~4 秒** | 取决于网络 |

---

## 11. 三件绝对不能做的事

| 禁止 | 后果 |
| --- | --- |
| **把管理密钥发给买家** | 他能自己无限发卡 |
| **把私钥（`license-private.pem`）给无关的人** | 谁都能伪造证书，整套授权作废 |
| **重新生成密钥对**（跑 `license-keygen`） | **所有已发出的证书立刻全部作废**，每个买家都要重发 |

---

## 12. 万一服务挂了（应急）

激活服务在 Cloudflare 上，**正常运行不用管**。如果 `/health` 打不开：

1. 换个网络 / 手机流量再试（可能是你这边网络问题）
2. 还不行 → 打开 <https://dash.cloudflare.com> 看 Pages 项目是否正常
3. 实在不行 → **临时改回手动模式**：让买家把机器码发给你，
   用签发工具（`license-issuer.exe`）为他签一张证书发过去
   （这条备用通道一直可用，见 `docs/授权门禁-完整说明.md` §3.2）

> **已经激活的老用户不受影响** —— 证书存在他本机，完全离线可用。
> 服务挂了只影响**新激活**。

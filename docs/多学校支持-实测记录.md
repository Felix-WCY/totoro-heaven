## 2. 独立域名的 5 所：**确认不可用**

实测用**免鉴权端点**打这 5 个域名（2026-10-23）：

| 主机 | `getSunRunSchoolList` | `getSunRunFirstConfiguration` |
| --- | --- | --- |
| `wxxcx.xtotoro.com`（对照） | **200 ✅ body[13]** | **200 ✅ 正常 JSON** |
| `yanggpa.ustl.edu.cn` | **401 ❌** | **401 ❌**（非 JSON） |
| `sunnysport.zjyc.edu.cn` | **503 ❌** | 401 ❌ |
| `shtc.jscn.edu.cn` | **401 ❌** | 401 ❌ |
| `sunrun.jsfpc.edu.cn` | **401 ❌** | 401 ❌ |
| `zhygp.just.edu.cn` | **503 ❌** | 401 ❌ |

**结论**：独立域名是**另一套后端**（网关/WAF 层就挡了），不是改白名单能解决的。
作者 `useMpReal.ts` 的原话「专属小程序等于另一套后端，本项目不支持」**是对的**。

> 曾于 2026-10-23 尝试放宽白名单，被这组实测数据否定，已撤回（见 commit `97144d4`）。

## 3. 共享域的 8 所：能连，但配置逐校不同

### 3.1 配置差异（实测 `getSunRunFirstConfiguration`，免鉴权）

| 学校 | `studentNameLoginType` |
| --- | --- |
| 南京航空航天大学 | **1**（姓名登录） |
| 南京航空航天大学研究生 | **1** |
| 重庆外语外事学院 | **1** |
| 龙猫大学（测试校） | **1** |
| 南开大学 | **0** |
| 天津师范大学 | **0** |
| 南京师范大学 | **0** |
| 浦江学院 | **0** |

**这证伪了"共享域就完全一样"的假设** —— 同一套代码，租户配置不同。

### 3.2 三个风控开关：**只有南航有记录**

`utils/mp/schoolGate.ts` 的 `VERIFIED_SCHOOLS` 里**只有一条**：

```ts
{ schoolCode: '98765', schoolName: '南京航空航天大学',
  knownSwitches: { sunrunStartFace: '0', sunrunPointRandom: '0', cameraFlag: false } }
```

其余 7 所**全仓库没有任何开关记录**（已搜索 `src/ utils/ composables/ server/ tests/ docs/`）。

⚠️ **「共享域学校都没开人脸」这个说法没有任何依据。** 作者的设计是：

> 支持范围 = 条件式：① 共享域 **且** ② **运行时**读到该校未开启三类风控

这是**且**，不是"共享域 ⇒ 没开人脸"。运行时读不到开关 → 也拒绝（`switches_unknown`）。

### 3.3 为什么免 token 查不到开关

全部 58 个端点的鉴权要求（`src/mp/endpoints.ts`）：

- **免鉴权 8 个**：学校列表 / 首配置 / 选学生 / 绑定登录 / 验证码 / code 换 token / 学生信息
- **需 token 50 个**：任务 / 线路 / 提交 / 判分 / 三个开关 / 摄像头 / 人脸 / 申诉 …… **全部**

试过两个风控配置端点（`selectSunRunStartConfiguration`、`selectSunRunRandomConfiguration`）：
**不带真实 token 时一律 `HTTP 200` + `obj: {}`** —— 查不出任何东西。

**所以：一个真实学生的 token 是唯一入口，没有变通。**

## 5. 验证协议（拿到一个 token 即可，约 10 分钟）

### 5.1 需要什么

**一个该校在读学生的 token**（只读）。获取方式：

1. 买家/学生用本工具「一键获取 TOKEN」或 Fiddler 抓包拿到 `WXXCX...`
2. 把 token 发给发布者（**只在私聊发，不要贴群**）

### 5.2 验什么

| 步 | 操作 | 通过标准 | 不通过的含义 |
| --- | --- | --- | --- |
| 1 | 输入 token → 点「读取真实账号与任务」 | 读出学校名/姓名/任务列表 | 报错 → 该校接口不兼容 |
| 2 | 看「任务与约束」卡片 | 里程/配速/时间窗/围栏都能显示 | 字段缺失 → 该校任务结构不同 |
| 3 | 看三个开关 | 全部为「关」 | **任一为「开」→ 该校永久不支持**（作者红线） |
| 4 | 真跑一次最短线路 | 「记录」页判为「有效」 | 判无效 → 判分口径不同，需调参 |

### 5.3 记录到哪

通过第 3 步后，把该校加进 `utils/mp/schoolGate.ts` 的 `VERIFIED_SCHOOLS`：

```ts
{
  schoolCode: '<该校 code>',
  schoolName: '<学校名>',
  verified: true,                    // ← 只有第 4 步通过才能写 true
  verifiedAt: 'YYYY-MM-DD',
  knownSwitches: { sunrunStartFace: '0', sunrunPointRandom: '0', cameraFlag: false },
  note: '<实测要点：里程 / 拟合度 / 配速区间 / 时间窗 / 围栏 / 判分结果>',
}
```

⚠️ **第 4 步没通过就不要写 `verified: true`** —— 那等于对买家撒谎。

## 6. 销售政策（基于以上事实）

| 学校 | 怎么卖 |
| --- | --- |
| 南京航空航天大学 | ✅ 直接卖 |
| 其余 6 所共享域学校 | 🟡 **先让买家发 token 验证**，或先给**3 天试用卡**，跑通再收钱 |
| 龙猫大学 `111051` | ❌ 不卖（厂商测试校） |
| 独立域 5 所 | ❌ 如实告知不支持 |

**宣传口径**：只写「支持南京航空航天大学」，其余写「其他学校支持试用」。
**不要写「支持所有学校」** —— 那是会招来退款和差评的承诺。

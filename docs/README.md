## 两条商业路径（先想清楚走哪条）

| | A. 手动签发 | B. 卡密 + 在线激活 |
| --- | --- | --- |
| 买家怎么拿授权 | 发机器码 → 签发者签一张 → 发回 | 付款收卡密 → 程序里输一次 → 自动激活 |
| 卖家工作量 | 每单约 2 分钟 | 每单 0 |
| 需要服务器 | 否 | **是**（一台即可） |
| 当前状态 | ✅ 可用（备用通道） | ✅ **已上线**（Cloudflare Pages，线上正在跑） |

## 常用命令速查

```powershell
# 完整验证（单测 + 3 个类型检查 + 接线契约）
npm run verify

# 打包主程序 → dist\totoro-heaven.exe
npm run sea

# 打包签发工具 → dist\license-issuer.exe
npm run build:issuer

# 启动激活服务（需 LICENSE_KEY_FILE / ADMIN_TOKEN / PORT）
npm run activation
```

## 一句话概括这套东西

```
证书绑机器码，私钥只在卖方手里
  → 客户端只带公钥，伪造不了证书
  → 拿不到证书，所有业务接口返回 402，界面自动跳到授权页
  → 手动模式：人签证书发过去
  → 在线模式：卡密换证书，可自动发货
```
